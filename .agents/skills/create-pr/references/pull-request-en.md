# Pull Request Template

## Summary

- Describe the user-visible or technical outcome.

## Changes

- List the main implementation changes.

## Verification

- List commands run and their results.
- State any verification not run and why.

## Checklist

- [ ] Scope is limited to this pull request.
- [ ] Tests and lint checks relevant to the change were run or documented.
- [ ] No secrets, credentials, or unrelated generated files are included.
